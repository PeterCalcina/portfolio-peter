# Peter Calcina — Portfolio

Portafolio personal (Signal Deck): proyectos, experiencia y contacto.

**Live:** [https://petercalcina.netlify.app](https://petercalcina.netlify.app/)

## Stack

- Angular 22 (standalone, zoneless)
- Tailwind CSS 4
- TypeScript 6
- Deploy en Netlify

## Desarrollo

```bash
npm install
npm start
```

Abre `http://localhost:4200/`.

## Build

```bash
npm run build
```

Salida: `dist/portfolio-peter/browser` (publicada por Netlify vía `netlify.toml`).

## Contenido

Textos, proyectos y experiencia viven en `src/app/core/content.ts` (ES / EN).
